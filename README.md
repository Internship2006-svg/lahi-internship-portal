# LAHI Internship Journey – Gamified Prototype

This version converts the Internship Toolkit into a mobile-first, gamified web experience.

## Files
- index.html – welcome screen
- journey.html – graphical journey map
- prepare.html – first interactive mission
- style.css – visual design
- app.js – available for future shared logic
- content.js – structured toolkit content
- manifest.json – app-style metadata

## Current prototype
Mission 01 includes:
- parent/guardian conversation
- consent & confirmation
- safety basics
- internship details
- task completion
- XP
- badge count
- progress
- localStorage persistence
